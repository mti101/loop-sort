# Loop Sort
Original Flutter conveyor-loop sorting puzzle. 200 solver-verified levels, boosters, lives/coins, daily reward, AdMob (rewarded, interstitial, banner) + UMP consent, remove-ads IAP.

- `lib/` game, UI, services · `assets/levels/levels.json` generated by `tools/levelgen`
- `tools/setup_android.sh` creates the Android scaffold locally; CI does it automatically
- `flutter test` runs engine parity, headless playback of all levels, and golden screenshots
- See `RELEASE.md` for publishing steps.
